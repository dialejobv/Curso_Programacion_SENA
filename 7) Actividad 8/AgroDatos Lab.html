¿Qué cardinalidad tiene cada relación?

Llave primaria y llave foránea

La llave primaria identifica cada fila. La llave foránea copia esa llave en otra tabla para relacionarlas: lote.id_finca apunta a finca.id_finca. El motor rechaza cualquier valor que no exista en la tabla padre.

Relación muchos a muchos

Un lote recibe muchos productos y un producto se aplica en muchos lotes. Eso no cabe en dos tablas: se resuelve con la tabla intermedia aplicacion, que además guarda la fecha y la cantidad.

Motor del simulador y diferencias con MySQL

El simulador usa SQLite compilado para el navegador. Las consultas de este curso son iguales en MySQL, con estas diferencias: en MySQL la llave autoincremental se escribe INT AUTO_INCREMENT PRIMARY KEY (aquí INTEGER PRIMARY KEY); MySQL tiene ENUM y DECIMAL (aquí se usan CHECK y REAL); las fechas se suman con DATE_ADD(fecha, INTERVAL 30 DAY) en MySQL y con date(fecha, '+30 days') aquí. Para ver las tablas usen SELECT name FROM sqlite_master WHERE type='table' (en MySQL: SHOW TABLES).
